# あさぶろ

あさぶろ（asaburodesu）のプロフィールサイト。HTML と CSS だけで構成し、GitHub Pages で公開しています。

## ローカルで確認

`index.html` をブラウザで開いてください。インストールやビルドは不要です。

## Deploy

`main` ブランチへ push すると `.github/workflows/pages.yml` が実行され、GitHub Pages にデプロイされます。

初回だけ GitHub リポジトリの `Settings > Pages` で `Source` が `GitHub Actions` になっていることを確認してください。
